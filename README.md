# Universal Converter

Qt-проект для точного перевода неотрицательных рациональных чисел между системами счисления.

## Что поддерживается

- основания от 2 до 500;
- целые числа;
- конечные дроби;
- периодические дроби: `0.(3)`, `1.A(B)`, `0.12(34)`;
- цифры `0..9`, `A..Z`, `a..z`;
- большие цифры в квадратных скобках: `[36]`, `[222]`, `[499]`;
- загрузка входных данных из файла;
- сохранение результата в файл;
- ограничение результата до 100000 символов.

## Формат входного файла

Файл должен содержать три строки:

```text
p
q
input
```

Например:

```text
16
2
A.F
```

## Основные классы

- `BigInteger` — длинная арифметика для неотрицательных целых чисел;
- `BigFraction` — точные дроби;
- `BaseParser` — разбор входного числа и построение дроби;
- `BaseFormatter` — перевод дроби в целевую систему;
- `BaseConverter` — общий класс для запуска конвертации;
- `MainWindow` — Qt-интерфейс.
